# VK Championship Landing

Responsive landing page for the VK Education Spring Championship focused on design and development.

## Features

* Responsive desktop and mobile layout
* Hero section with visual composition
* Championship information
* Design and development directions
* Prize section
* Email subscription form
* Responsive mobile navigation
* Scroll reveal animations
* Semantic HTML structure
* Basic accessibility support
* Loading and interaction states
* Production-ready build

## Tech Stack

* React
* TypeScript
* Vite
* SCSS
* ESLint
* CSS
* HTML5

## Responsive Design

The layout is designed for:

* desktop
* tablet
* mobile
